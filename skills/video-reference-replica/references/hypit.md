# Hypit 对接要点

只在环境确实安装 Hypit 时使用。若同时存在 Hypit 技能，读取该技能以获取当前运行时与接口说明。本文件不是安装器，也不规定版本特定命令。

- 先定位用户指定工程及选定成片；检查项目入口、组件与音轨引用，避免编辑弃用分支。
- 通常使用 SVML 描述时间线与组合、SVS 管理外观、SVRun 提供执行入口。实际目录和命令以工程及 CLI 帮助为准。
- 将产品几何、镜头段落、文字生成与配乐拆为可维护职责；时间表只保留一个权威来源。
- 修改组件后运行工程已有构建步骤；若存在生成的浏览器代码，交付快照必须与最终源码及实际渲染一致。
- 提交渲染后记录构建编号。观察超时不代表渲染失败，不因此重复提交；检查实际状态。
- 媒体工具进程不可用时先检查路径与日志，区分启动检查超时、浏览器缺失和渲染错误。不要无依据重装或修改全局配置。
- 导出时明确输出路径。文件已存在时使用新临时路径验证，再按用户的版本管理要求保留最终文件。
- 仅换音乐可用 FFmpeg 复制视频流并替换音轨；保留采样率、时长与淡出的一致性，记录基底视频及后处理方式。
- 交付工程要包含实际使用的字体、地图、音轨和作者文件；记录外部依赖。不要称其为剪映工程或独立安装包。
