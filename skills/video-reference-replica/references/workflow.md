# 详细制作流程

以下包装案例只用于解释转译方法，实际内容以用户产品为准。阶段标准由制作方自检，不默认每一步都需要用户批准。

## 二、完整执行顺序

需求卡 → 参考拆解 → 产品转译 → 镜头与音乐时间表 → 关键片段试制 → 全片制作 → 分项验收 → 交付与归档。

每一步由制作方自行核对标准。未达标时回到对应步骤，不把模糊问题反复交给用户描述；只有品牌事实、产品信息、版权授权、预算等确实缺失时才询问。

### 01｜建立需求卡

输入：风格参考、产品参考、品牌资料、发布用途。

执行：
- 标明每个参考文件的用途，不按“最新提供的参考”覆盖原来的风格要求。
- 写清目标受众、核心卖点、品牌中英文、必须出现的信息。
- 确定画幅、时长范围、字幕语言、声音形式和预算。平台名称不等于画幅：横版转竖版需重新构图，不能拉伸素材。
- 区分实物依据与示意设计；无证据不加入承重数值、测试通过等宣传结论。

产出：一页需求卡。
通过标准：制作方能用一句话说明“给谁看、展示什么、沿用哪支片子的什么特点”。

记录本项目的品牌、核心卖点、产品组成、地域信息与成本约束，不继承其他项目的具体内容。

### 02｜拆解第一参考

输入：风格参考原片。

执行：完整观看一遍，再按镜头和转场拆解。保留原始宽高比；在关键运动开始、峰值、结束处取帧。记录声音重音如何对应动作。

每个镜头必须记录：
- 起止时间、持续时长、主要信息。
- 主体位置与画面占比、背景、颜色、光影。
- 相机是推进、拉远、绕行还是滚转；物体自身怎样运动。
- 文字出现、停留、退出的方式和可读时间。
- 前一镜头留下什么，下一镜头如何接住它。
- 音乐重拍对应哪个具体动作，而不只是对应剪切点。

产出：镜头拆解卡与关键帧图集。
通过标准：能解释每次转场为什么成立，不能只写“高级、丝滑、有科技感”。

### 03｜把参考表达转译到自己的产品

输入：拆解卡、产品造型依据。

执行：逐镜填写“保留的表现方法—替换的产品内容—转场连接物”。

包装示例：
- 材料聚合 → 纸纤维汇聚、瓦楞成形 → 纸板边缘带出箱体。
- 产品细节推进 → 内衬定位、轴件支撑 → 沿结构线继续移动。
- 产品组合展示 → 纸箱、内衬、托盘形成完整方案 → 缩小定位到业务所在地。
- 地理位置展示 → 地图突出项目指定地点 → 货车前景遮挡接运输。

产出：改编分镜，注明参考依据与替换理由。
通过标准：观众能从开头元素联想到产品；同一支片子的视觉风格贯穿始终。不要把创意广告改成普通装箱说明视频。

### 04｜建立唯一的镜头／音乐时间表

输入：改编分镜、候选 BGM 或配乐草稿。

执行：
- 为每个动作分配固定编号：材料成形、产品亮相、内衬定位、方案展开、地图定位、运输进入、品牌收尾等。
- 同时填写动作开始、视觉峰值、落定、文字阅读区间和音乐重拍位置。
- 先试听音乐的方向，再精修动画。配乐确定后，让动作峰值对齐重音；个别位置可小幅调整音乐速度或动作时长。
- 主要动作使用强拍，次要动作使用轻提示。不要给每次移动都叠加重鼓。
- 改镜头顺序时，同时更新声音提示、字幕、转场与时间表。

产出：声画共用的时间表。动画代码和配乐脚本从同一份动作数据读取，避免分别手写两套时间。
通过标准：每个强重音都有画面理由；画面重要落点也有明确的声音安排。

激昂推进配乐建议：开场蓄势 → 产品亮相建立节奏 → 细节段稍收 → 完整方案增强 → 地图短暂回落 → 运输进入高潮 → 品牌和弦收束。可从约 125–140 BPM 试起，最终按参考节奏和听感决定。激昂应来自节奏、和声与层次变化，不能只增加音量和音轨数量。

### 05｜先做关键片段，不直接做整片

输入：基础模型、时间表。

执行：先以低成本预览验证三个风险最高的片段：
1. 产品关联开场与第一次亮相。
2. 最复杂的连续转场，包含空间文字。
3. 方案展示到地图、再到运输的交接。

试片长度按转场完整性决定，通常每段约 5–10 秒。可以先用白模，但应带基本节奏音轨。

产出：少量关键试片及制作方的差距记录。
通过标准：风格方向接近第一参考、产品可识别、转场有铺垫、动作与重拍一致。没通过就先修关键片段，不用全片渲染掩盖方向问题。

### 06｜制作完整三维动画

输入：通过自检的试片、模型与分镜。

执行：
- 模型拆为纸箱、箱盖、内衬、隔板、产品、托盘、束带等独立对象；建立装配层级与运动依赖。
- 先锁定结构与相机，再细化材质、光影和运动模糊。
- 连续转场保留空间关系：使用前景遮挡、相同形状或结构线连接、物体延续运动、镜头穿越明确开口等方式。
- 相邻段衔接检查位置、朝向、尺度与运动速度；遮挡切换必须等遮挡真的覆盖画面后发生。
- 不用淡入淡出代替所有转场，也不让模型突然出现或相机穿实体来冒充“一镜到底”。
- 先解开束带再开盖；先腾出空间再移动内部物体。碰撞检查应包含材料厚度。

文字单独处理：
- 按实际字形上下界生成画布，保留上下边距，不能只限制文字宽度。
- 标题放在画面空白区；需要时调整运镜为文字留空间。
- 印在箱面的标识遵守模型遮挡；用于阅读的标题不能被产品挡掉。
- 正常速度检查阅读时间。短标题可先按约 1.5–2 秒的可读窗口设计，再按内容与参考调整；淡入淡出不全算有效阅读时间。

产出：带完整音乐的全片预览。
通过标准：先能稳定看清、听清，再追求特效丰富。
