# 参考驱动的产品视频复刻

目标是保留参考的表达方法，并用用户产品形成合理的视觉连接。不要把复刻改成自由创作，也不要把产品造型参考误当作风格参考。

## 先判断任务范围

- 新片：先明确参考职责和改编镜头，再验证关键片段，最后完成全片。
- 局部修订：以用户选定版本为基线，只改指定范围，检查相关转场、文字与配乐；不要从头换风格。
- 仅移动镜头：连同进出转场、字幕和音乐提示一起调整；不要自行延长片长或重做无关镜头。
- 仅更换 BGM：尽量保留原视频流，替换音轨后检查编码后的同步和响度。

品牌、造型、画幅、预算等已有信息沿用会话，不重复询问。制作判断由制作方承担；只有缺失事实确实影响结果时才集中提问。用户没有明确授权时，不把此前项目的付费许可或清理许可沿用到新项目。

## 执行工作流

首次制作或方向不清时，阅读 [详细流程](references/workflow.md)。按需要复制 [项目工作底稿](assets/project-workbook.md)，不要把空模板当成完成品。

1. **区分参考职责。** 风格参考决定运镜、构图、节奏、文字和转场；产品参考决定外形、结构与装配关系。允许同一文件兼任，但须写明。保持参考原始宽高比。
2. **逐镜拆解。** 记录运动开始、峰值、落定、阅读窗口及声音落点；解释相邻镜头靠哪个物体、结构线、方向或遮挡相接。不要只写“高级、丝滑”。
3. **产品转译。** 每镜头写明保留的方法、替换的内容与转场连接物。开场必须呼应产品。例如把编织材料的聚合转译成纸纤维／瓦楞成形，不能直接照搬无关色彩和符号。
4. **统一声画时序。** 建立唯一动作时间表，包含镜头编号、动作峰值、音乐提示和文字阅读区间。动画与配乐从同一数据读取。移动或变速时同时更新全部依赖。
5. **先试高风险片段。** 优先做产品关联开场、复杂空间文字或连续转场、关键场景交接。试片带基础节奏。制作方先对照参考自检，方向不对时先修试片，不盲目堆积整片版本。
6. **完成全片。** 先结构和运镜，后材质与细节。保留物体运动依赖和材料厚度。用相邻画面的位置、尺度、方向与速度衔接；只有前景真正覆盖画面时才切换被遮挡场景。
7. **分项验收。** 交付前阅读 [验收清单](references/quality-checks.md)。风格、造型、文字、穿模、声音与文件完整性分别检查。数值检查通过不代表主观效果达标。
8. **交付并记录。** 提供最终视频、需要的独立音乐、可编辑工程、明确路径及已验证／未验证项。仅在用户要求时清理旧视频；先核对保留文件与清单，保护原始素材和无关项目。

## 实现选择

本技能负责导演与验收流程，不自带渲染引擎、音乐模型或 API 密钥。使用当前环境已安装且适合任务的工具。

使用 Hypit 时阅读 [Hypit 对接要点](references/hypit.md)；其他引擎按其实际接口执行，不套用 Hypit 命令。如果必要的媒体查看、渲染或声音试听能力不可用，继续完成可验证部分并准确说明缺项，不能声称已看过、听过或导出。

BGM 先确定情绪、推进曲线与试听方向，再精修卡点。主要动作落强拍、次要动作轻提示。激昂来自节奏、和声与层次发展，不靠持续叠加音轨或提高音量。节奏参数由本片决定，不把某次项目的 BPM、品牌、地图位置或模型尺寸当成通用要求。
